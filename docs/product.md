# Product and interaction contract

One creator, one creator-owned Twitch channel. Ordinary messages enter privately; creator chooses an actual finalized recording and associates one immutable source message with a half-open media interval. Default review is private. No unanswered-message leaderboard or promise that every viewer gets a reply.

Flow: source setup → record/import → add/receive message → new exchange → select correct message/recording → preview boundaries and lead-in → save revision → approve exact revision → derived-media job → local replay → explicit external snapshot preparation → after authorization, verified hosting → separate Share in Twitch. Publication, delivery and viewer observation are distinct.

Review keeps the original message visible beside real playback. Transcript sentences are optional timing aids, not replacement speech. Corrected captions remain text edits; recordings remain immutable. Messages are React text nodes; no HTML interpretation.

Design: warm paper, forest green, expressive but readable headings, restrained orange error states, generous conversation cards, and a connecting line from message to response. The queue is a work surface rather than analytics. Empty, removed and unavailable states are intentional. Mobile keeps message context above playback, with no automatic audio.

Fixtures use Mira, Kai and Noah as clearly labelled sample names and generated test-pattern/tone recordings. They are not audience evidence. A live solo demonstration must say the creator sent the message and responded aloud.
